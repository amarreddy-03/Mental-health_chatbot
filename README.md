# Mental Health Chatbot

A simple Python-based Mental Health Chatbot designed to provide basic supportive responses and guidance based on common student concerns.

## Features

- Simple chatbot interface
- Provides supportive responses
- Handles common student questions
- Easy to use
- Built using Python

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## Project Files

- app.py – Main application
- responses.py – Chatbot responses
- style.css – Website styling
- requirements.txt – Required Python packages

## How to Run

1. Clone the repository.
2. Install the required packages:

```bash
pip install -r requirements.txt
